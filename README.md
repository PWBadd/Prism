# Prism

Медиаплеер (mp3 / mp4) для Android: жидкое стекло, темы, плейлисты, плавные затухания.
A media player (mp3 / mp4) for Android: liquid-glass UI, themes, playlists, smooth fades.

## Как собрать / How to build
1. Android Studio (стабильная) + SDK 35. Папку проекта лучше держать НЕ в OneDrive (например C:\Prism).
2. File -> Open -> папка `Prism` -> дождись Gradle Sync.
3. Build -> Build APK(s). APK: `app/build/outputs/apk/debug/app-debug.apk`.
4. Или залей проект на GitHub: вкладка Actions -> Build APK -> Run workflow, APK будет в Artifacts.
